**The mod matrix release.** Both synths' modulation matrices now run on one shared engine, and the curve control they share was rebuilt: what were two text pick-lists per curve is now a single glyph button opening a 3×3 picker. Routes gained an on/off switch, and the scale VCA gained the polarity axis the primary source has always had.

**Your patches still mean what they meant.** The curve split kept the old `polarity × 3 + shape` numbering, so the four pre-split spellings (`lin`, `exp`, `log`, `bipolar`) decode unchanged, and the scale VCA's new resting polarity *is* the old code path rather than an approximation of it.

# Both synths

### The curve is two axes, and looks like what it does

A route's shaping was always a **polarity** that maps the source's range and a **shape** that bends the response within it — but the faceplates spelled that as two adjacent drop-downs reading `Bipolar` + `Exp`, and left you to imagine the composition. Each pair is now **one button drawing the resulting curve as a glyph**, which opens a 3×3 picker: polarity down, shape across, dismissing on pick. The glyph is plotted from the same arithmetic the audio thread runs, so the picture cannot drift from the sound.

That reclaims two columns per curve — four per row, since the scale VCA has a curve of its own.

### The scale VCA gets the same nine curves

The secondary scale source (the VCA on a route's depth) had the bend but not the range mapping: three options where the primary source had nine. It now carries both axes.

The motivating case is real: `voice-position` scaling a route could only ever mean "the voices on one side of the spread". With **Abs** it can now mean "the voices at both edges, and not the ones in the middle" — the same rectification the primary axis got for exactly this reason. **Bipolar** gives you a gate that stays shut over the source's lower half.

`None` is the old behaviour, bit for bit — it is the old code path, not a reimplementation of it.

### One matrix engine, one FX kernel set

Under the hood, both synths now route through a shared `vxn-core-matrix`: neither carries its own slot type, curve axes, scale VCA, route compilation, evaluator or smoother bank. The same consolidation finished on the FX side — the stereo delay and the master limiter join the phaser, chorus, reverb and dynamics block as shared kernels, and the old outer bypass fades are gone in favour of one declick idiom inside each kernel.

This was meant to be inaudible and, for vxn-2, it was: the render hash did not move once across either consolidation. **VXN1b's delay was re-baselined** when it adopted the shared kernel — the one change here that reaches the ear, listened to before it landed.

# VXN1b

- **A switched-off `Env → Amp` route no longer feeds the VCA.** A disabled route was still contributing to the amp path — the sort of bug that reads as "this patch is louder than it should be" rather than as anything obviously broken.
- **Matrix topology edits no longer take a mutex on the audio thread.** Rewiring a route while notes are sounding used to make the audio thread contend for a lock; edits now ride a wait-free ring instead.
- **The delay is the shared stereo kernel**, with its damping gated off to preserve the voicing. This is the re-baselined change noted above.
- **Routes switch on and off.** A slot can be disabled without losing what you wired into it, so you can audition a route out and back without rebuilding it. (VXN2's rows have always had this.)

# VXN2

- **A patch swap fades out and hard-resets** rather than simply silencing, so the outgoing preset's ringing voices do not smear into the new one.
- **The matrix accumulators are dest-major**, which is what lets the evaluation vectorise across the stack.
- The master limiter sits behind a bypass that fades, so switching it in and out is silent.
- The mod-matrix overlay reserves the scrollbar's width, so the rows stop shifting when it appears.

# Web builds

Both browser synths ship the above, and one fix specific to them: **the scale VCA's curve was not reaching the engine in either web build.** The faceplate sent it, the engine understood it, and the JavaScript between them dropped it — so the picker moved and the sound did not. Fixed on both sides of both ports, with the wire's field set now pinned against the engine's own vocabulary in tests.

Play them in the browser — no install, nothing to scan:

- **VXN2** — https://vulpuslabs.com/products/vxn-2/web/

# Downloads

macOS builds are universal (Apple Silicon + Intel); Windows is x64. Both formats are the same engine — take CLAP if your DAW supports it.

macOS will quarantine a plugin downloaded from a browser. If it does not appear after a rescan:

```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP/vxn1b.clap
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/VXN1b.vst3
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/CLAP/VXN2.clap
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/VST3/VXN2.vst3
```
